# Anna Clerk Foundation — Post 07

Four square Facebook images, each 1200 × 1200 px, ordered 01–04. Upload all four as one multi-image post; this package does not require carousel functionality.

Art direction: photo-journal/editorial layout with documentary photography, modular ivory and navy text panels, teal rules and field-note numbering. The established Anna Clerk Foundation header, palette and serif/sans pairing are retained.

Files:

- Four publishing JPGs in the root folder
- PNG masters in `masters/`
- A 2 × 2 review image: `post-07-grid-preview.jpg`
- Caption and provenance: `post-07-caption-and-sources.md`
- Original source photographs and brand header in `source-assets/`
- Reproducible Sharp build script: `build_post07.cjs`
